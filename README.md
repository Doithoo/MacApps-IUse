# 我的 Mac 软件清单

![Last Updated](https://img.shields.io/badge/last%20updated-2026--06--14-blue)

这是我当前 Mac `/Applications` 目录中已安装的第三方软件清单，按使用场景分类整理，并持续维护。

扫描口径：以 `/Applications` 下的 `.app` 为准，已去重，并排除 Safari、Pages、Numbers、Keynote、Xcode 等 Apple 或 macOS 自带软件。
